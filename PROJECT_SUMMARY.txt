EXECUTIVE SUMMARY
================================================================================
This is a multi-modal graph neural network for predicting gene regulation in
promoter regions by fusing three complementary data sources:
1. 3D Genome Topology (Hi-C contact maps and PCHi-C promoter-capture interactions)
2. Promoter DNA Sequence (±1–8 kb around transcription start sites)
3. Histone Modifications (ENCODE epigenomic ChIP-seq marks)

The model simultaneously predicts four regulatory outcomes (link strength,
expression, tissue-specificity, tissue identity) validated with gene-grouped
cross-validation to prevent data leakage.

PHASE 2: FEATURE ENGINEERING (Notebook Part 1)
-----------------------------------------------
Load raw data (loops, sequences, histones, Hi-C)
  ↓
[Cell 3–8: Loop Parsing & Validation]
  • Parse PCHi-C loop files (*_merged_loop.txt)
  • Filter by CHiCAGO score (≥ 5.0)
  • Verify genes fall inside bait fragments (hg19 assembly check)
  • Filter for expressed genes (TPM ≥ 1.0)
  ↓
[Cell 9–11: Promoter Sequence Extraction]
  • Extract ±1 kb (or ±8 kb in 1Mb variant) around canonical TSS
  • Cache as uint8 one-hot encoding ([A/C/G/T] per position)
  • Memory-aware: large windows stored as uint8, cast to float32 per batch
  ↓
[Cell 12–14: Histone & Hi-C Aggregation]
  • Query ENCODE bigWigs for histone marks at bait fragments
  • Use liftOver chains to lift coordinates (hg19 → GRCh38) for queries
  • Query Juicer .hic files for contact frequencies
  • Mask missing data (never zero-fill):
    - Absent histone → signal=0, mask=0
    - Missing tissue Hi-C → has_hic=0
  ↓
[Cell 15–18: Graph Construction]
  • Per promoter × tissue: build contact subgraph
  • Anchor node: bait fragment (the promoter)
  • Edges: top-k prey fragments by CHiCAGO score (max 32 neighbors)
  • Node features: sequence, histone marks, CTCF, degree
  • Edge features: CHiCAGO score, Hi-C contact frequency, distance
  ↓
[Cell 19–20: Train/Test Stratification]
  • Gene-grouped 5-fold CV (not random rows)
  • Prevents leakage: same gene never appears in both train & test
  • Label (tau = tissue-restriction) is constant per gene
  ↓
[Cell 21: Data Audit]
  • Check variance, class balance, missing values, feature ranges
  ↓
Processed feature tensors (sequence, graphs, embeddings)

PHASE 3: MODEL ARCHITECTURE (Notebook Part 2)
----------------------------------------------
TWO-TOWER ENCODER (or THREE-TOWER in Trimodal Variant):

TOWER A: Sequence Encoder (HyenaDNA-style)
  Input: 16 kb (or 1 Mb) DNA sequence as one-hot [A/C/G/T]
  • Implicit long-convolution with learnable filter (O(L log L) via FFT)
  • Positional encoding → MLP generates filter coefficients
  • Reverse-complement equivariant: z(seq) = z(reverse_complement(seq))
  Output: z_seq (sequence embedding)

TOWER B: Structure + Epigenomics (Graph Attention Network)
  Input: Subgraph (nodes = fragments, edges = CHiCAGO/Hi-C)
  • Graph Attention Layers: learnable edge attention
  • Per-node features: histone marks, CTCF, position, degree
  • Mean pooling over all nodes
  Output: z_struct (structure embedding)

[TRIMODAL ONLY] TOWER C: Epigenomics Encoder
  Input: Histone/CTCF at anchor fragment only
  • Separate EpiEncoder network
  Output: z_epi (epigenomic embedding)

FUSION LAYER:
  • 2-tower: FiLM fusion (z_seq modulates z_struct)
  • 3-tower: GatedFusion (learned per-modality gates) + InfoNCE alignment
  Output: z_fused (combined embedding)

FOUR SUPERVISED PREDICTION HEADS:
  Head 1 (Link Prediction):
    Target: CHiCAGO ≥ threshold (1/0)
    Loss: BCE + focal weighting

  Head 2 (Expression):
    Target: TPM ≥ 1.0 (1/0)
    Loss: BCE + focal weighting

  Head 3 (Tissue-Restriction):
    Target: tau ≥ 0.85 (1/0)
    Loss: BCE + focal weighting

  Head 4 (Tissue Classification):
    Target: Multi-class over 46 tissues
    Loss: Cross-entropy

TRAINING CONFIGURATION:
  • Optimizer: Adam with gradient clipping
  • Epochs: 40 (standard), 5 (fast_mode)
  • Validation: on held-out fold; metrics = AUROC, AUPRC, F1, calibration error
  • Checkpointing: best model per fold saved

ABLATION STUDIES (same config, different data):
  • GAT-only: z_seq removed, use only z_struct
  • Sequence-only: z_struct removed, use only z_seq + histones
  • Combined (baseline): both towers active
  • DHL Ensemble: frozen embeddings fed to logistic regression + SVM/RF/kNN/GB

PHASE 4: VALIDATION (Notebook Part 3)
--------------------------------------
After 5-fold gene-grouped CV, run additional validations:

1. CHROMOSOME-BLOCK CV
   For each chromosome:
     • Train on all other chromosomes
     • Test on held-out chromosome
     → Measures generalization across genomic regions

2. LEAVE-ONE-TISSUE-OUT (LOTO)
   For each of 46 tissues:
     • Train without that tissue
     • Test on that tissue
     → Measures generalization across cell types

3. BLOOD-AS-TEST
   • Train on all non-blood tissues
   • Test on blood samples
   → External hold-out proxy for real-world generalization

4. DHL HYBRID ENSEMBLE
   • Freeze embeddings from main model
   • Train classical ML algorithms (logistic/SVM/RF/kNN/GB)
   • Evaluate on test fold
   → Validates if learned embeddings transfer to non-neural models

KEY TECHNICAL INNOVATIONS
================================================================================

1. HyenaDNA Sequence Encoder
   Why: O(L log L) complexity via FFT; handles full 16 kb promoter in one
   receptive field (vs. ~500 bp for CNN)

2. Reverse-Complement Equivariance
   Why: DNA sequence is strand-agnostic; model respects this symmetry

3. Gene-Grouped Cross-Validation
   Why: Prevents data leakage; same gene never in train & test simultaneously

4. Coordinate Lifting
   Why: Query with correct assembly version (hg19 for PCHi-C, GRCh38 for Hi-C);
   saves GB of disk space

5. Masked Missing Data
   Why: Distinguishes absence from zero signal (important for chromatin data)

6. Multi-Head Prediction
   Why: Four tasks simultaneously predict different regulatory aspects

7. Ablation Arms
   Why: Isolates contribution of each modality (graph, sequence, epigenomics)

8. DHL Ensemble
   Why: Validates if frozen embeddings generalize to classical ML algorithms

9. uint8 Sequence Bank
   Why: At 1 Mb scale, memory-efficient without on-the-fly recomputation

SCIENTIFIC CONTEXT
================================================================================

Why This Matters:
  • Gene regulation is fundamental to understanding development, disease, evolution
  • 3D genome structure (Hi-C) revolutionized chromatin biology, but raw contacts
    alone don't predict function
  • Combining topology, sequence, and chromatin state offers a more complete picture
  • Graph neural networks naturally capture network structure; sequence encoders
    capture motifs
  • Multi-modal fusion shows where each data type contributes most

Generalization:
  • This architecture could apply to other gene regulation tasks (promoter-enhancer
    interactions, splicing, etc.)
  • The modular notebook-generation system allows easy experimentation with new
    features or architectures
  • Cross-validation strategies (chromosome-block, tissue LOTO) test real-world
    robustness
